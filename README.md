# mhw-ml-southwestern-atlantic
This repository contains the results of the machine learning models and the hyperparameters used in the study “Evaluation of Machine Learning Techniques for Identifying Atmospheric Predictor Variables of Marine Heatwaves in the Southwestern South Atlantic”, presented at the Brazilian Congress of Oceanography (CBO 2026).

## Models

The repository includes results from the following machine learning approaches:

- **Decision Tree** — multiclass classification.
- **LightGBM** — multiclass classification.
- **LightGBM** — regression.

## Repository Structure

- **`hyperparameters/`** — Contains the hyperparameters used in the machine learning models for classification and regression.

- **`model_metrics/`** — Contains the model performance results, including confusion matrices and evaluation metrics for the classification and regression models.
